# 🌍 TripSmart

### Plan Smarter. Travel Better.

TripSmart is an AI-powered travel planning application designed to make trip planning simple, personalized, and organized. It brings destination discovery, itinerary planning, budget management, travel information, and trip preparation together in one platform.

## ✨ Features

- 🗺️ Destination exploration and travel discovery
- 🤖 Personalized AI-powered travel suggestions
- 📅 Day-by-day itinerary planning
- 💰 Smart budget planning and expense tracking
- 🌦️ Real-time weather information and forecasts
- 💱 Currency conversion and exchange-rate information
- 🛂 Destination visa and travel requirement information
- 💎 Hidden gems and local travel recommendations
- 🎒 Smart packing checklist
- ✅ Pre-departure travel checklist
- 🗺️ Attraction route planning
- 🔗 Trip sharing with shareable links
- 📄 Trip summary and PDF export
- 💾 Save and manage planned trips
- 🌐 Multilingual support
